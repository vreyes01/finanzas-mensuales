# Finanzas mensuales

App web para gestionar tus finanzas del mes: ingresos, gastos fijos y variables, meta de ahorro, metas con fecha y cambio de moneda con tipos de cambio manuales.

- Un solo archivo (`index.html`), sin dependencias ni servidor.
- Los datos se guardan en el navegador (localStorage) de cada dispositivo.
- Respaldo y restauración en `Ajustes` (JSON) y exportación de gastos (CSV).
